Initialization & Resource Management

Initialization & Resource Management Overview

Initialization & Resource Management contains:

  • RwEngine Overview includes memory handling, plugin registration, setting and querying video modes, initializing and terminating RenderWare Graphics
  • RwFreeList Overview - allocates memory for lists of identical data types
  • Memory & File Interfaces - file and memory interfaces
  • RwPlugin Overview - plugin attachment API
  • RwResources - Resource Arena cache
