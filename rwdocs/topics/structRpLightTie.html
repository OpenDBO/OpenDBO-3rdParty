Detailed Description

RpLightTie is a linked list of lights inside world sectors. These are created when frame hierarchies are updated as part of an RwCameraBeginUpdate. This is used for determining which lights influence a world sector and the atomics inside it. Creation and destruction of RpLightTies is internal to the world plugin.
