RenderWare Graphics 3.2 release notes.

Introduction

Welcome to the RenderWare Graphics SDK. This deliverable includes the full SDK at version 3.2.

  • Since the last release of RenderWare Graphics, we have targeted several major areas in development.
  • The introduction of new technology, features and optimizations.
  • Increased run-time stability, better documentation and SDK presentation.
  • Improved and optimized art-path. This is part of an ongoing program to make the transition from modeller to engine for artists easier, more customizable and faster.
  • The dual task of managing the need for multi-platform portability, and also platform specific enhancements.
RenderWare Graphics version 3.2 does have some significant differences from its predecessors.
