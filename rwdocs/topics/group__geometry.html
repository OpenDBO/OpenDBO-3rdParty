Detailed Description

Basic Geometry, Skinning, Morphing, Delta Morphing & Particles

Geometry Overview

Geometry contains:

  • Basic Geometry
    • Materials
      • RpMaterial Overview - color, texture, specularity, ambient reflectivity and diffusion
      • RpMatFX Plugin Overview - material effects including environment mapping, bump mapping, and dual pass

    • RpAtomic Overview - container objects for RpGeometry's and RwFrame's
    • RpGeometry Overview - container object for dynamic model data
    • RpMorphTarget Overview - keyframe animation
    • Meshes
      • RpMesh Overview - caching system designed to speed up rendering
      • RtVCAT Toolkit Overview - vertex cache aware tristripper
    • RpADC Plugin Overview - address control flag generation
    • RtGCond Toolkit Overview - geometry conditioning
    • RtWorldImport Toolkit Overview - create a static world within an RpWorld object
    • RtWing Toolkit Overview - implement, maintain and operate on polygons using wing/half-edge data structure
    • RtWorld Toolkit Overview - additional functionality for RpWorld
  • Skinning
    • RpSkin Plugin Overview - animate a model while reducing the 'folding' and 'creasing' of polygons as model animates
    • RtSkinSplit Toolkit Overview - render more bones than supported by the platform
  • Morphing
    • RpInterpolator Overview - instance of dynamic geometry data, interpolated from keyframes stored in Morph Targets
    • RpMorph Plugin Overview - morph animation
  • Delta Morphing
    • RpDMorph Plugin Overview - delta morph animation
  • Particles
    • RpPrtStd Plugin Overview - basic particle animation and management system
    • RpPTank Plugin Overview - driver level particle manager and particle container
    • RpPrtAdv Plugin Overview - advanced particle system (part of the FXPack and found in the FXPack folder)
  • Bézier Patches
    • RpPatch Plugin Overview - includes support for quadrilateral and triangular bi-cubic patches
  • Collision Detection
    • RpCollision Plugin Overview - detects collisions with atomics or the static geometry of a world
    • RtPick Toolkit Overview - pick objects in a scene under a particular pixel location of a camera's image raster
