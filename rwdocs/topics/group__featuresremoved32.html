Features Removed
[3.2]

Archived components from RenderWare Graphics

The RenderWare Graphics team endeavors to support code as long as it is useful. Sometimes components no longer have value or are no longer maintainable - these we transition out of the SDK over a period of time.

SoftImage Support

Although you can use the SoftImage Exporter and recompile your assets for 3.2, it is not something that has been maintained for this release and its functionality is the same as the previous version.

Archived Features & Plugins

Exporters supporting RpPrtSys, legacy RpSkin, RpAnim will be available in the archive. The mainstream Exporters will not support these features.

Particles [RpPrtSys] Plugin - a new particle system is planned for RenderWare Graphics version 3.3. The reason it being archived at this stage is to reflect that it will be superceded at the next release.

.ska Skinning animation file support.

The legacy animation of RpSkin will no longer be shipped with RpSkin from this release. Support for RpSkin legacy animation will also be removed from the RenderWare Graphics exporters.

Features planned for removal from the archive

These functions will no longer be supported.

  • RpLabel
  • RpPrtcls
  • RpMemInfo
  • RpMemleak
  • RpRefine
  • RpVRML
  • RpBone
