The Core Library

The rwcore library provides the fundamental RenderWare Graphics features. When creating a RenderWare Graphics application, this library must always be linked.

Functionality includes:

  • Immediate Modes (2D RwIm2D and 3D RwIm3D )
  • Plugin Management
  • Base Datatypes
  • Cameras RwCamera
  • Frames RwFrame
  • the RenderWare Engine RwEngine
RenderWare Graphics uses an object-oriented design philosophy, so this documentation is split across a number of objects.

These objects are implemented in C, so C terminology is generally used, rather than C++ -- hence 'functions' instead of 'methods' and 'elements' instead of 'members'.

If you are new to RenderWare Graphics programming, please read through the supplied User Guide. The RenderWare Graphics Engine RwEngine API is usually the starting point for new developers.
