Detailed Description

This type represents the data required by the RpBuildMeshGenerateTriStrip function to tri-strip a mesh. This data must be the user-supplied data passed into RpMeshSetTriStripMethod when using RpBuildMeshGenerateTriStrip.

See also:
RpMeshGetTriStripMethod , RpMeshSetTriStripMethod , RpBuildMeshGenerateTriStrip , RpTriStripMeshTunnel
