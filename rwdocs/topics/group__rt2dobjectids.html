Rt2d Object IDs
[Rt2d]

Rt2d list of fundamental object IDs used for streaming.

  • rwID_2DBRUSH used by Rt2dBrushStreamRead
  • rwID_2DFONT used by Rt2dFontStreamRead
  • rwID_2DOBJECTSTRING used by Rt2dObjectStringStreamRead
  • rwID_2DPATH used by Rt2dPathStreamRead
  • rwID_2DPICKREGION used by Rt2dPickRegionStreamRead
  • rwID_2DSCENE used by Rt2dSceneStreamRead
  • rwID_2DSHAPE used by Rt2dShapeStreamRead
