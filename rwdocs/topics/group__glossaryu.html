Glossary entries beginning with U.

Up Vector

The "Up vector" is one of the vectors in a RenderWare Graphics matrix. The up vector corresponds to the 'y' axis in a right-handed, xyz coordinate system.

See also:
At Vector , Right Vector

Unicode

Unicode defines a 31-bit character set. A font is considered to be Unicode if it contains characters outside the ASCII character set.

Unicode code characters in a font are encoded using the UTF-8 format in the font metrics file.

RenderWare Graphics supports Unicode through the Rt2d toolkit. Font formats are saved in .met file format in UTF-8 format.

See also:
UTF , UCS , Rt2d Font Format , MET Format

UCS

Universal Character Set.

UCS contains all character set standards. It is based on 4 bytes per character (32-bit) coding scheme with 2 byte per character (16 bit) coding scheme forms the bitmap (UCS-2).

See also:
Unicode , UTF , MET Format , Rt2d Font Format

UTF

UCS Transformation Format.

Unicode code characters in a font are encoded using the UTF-8 format in the font metrics file format and the Rt2d toolkit.

The UTF-8 stores 1 byte per character (8-bit) lossless encoding of Unicode characters.

See also:
Unicode , CJK , UCS , MET Format , Rt2d Font Format

UVs

The coordinates that determine which texel in each texture is assigned to each vertex in an object. Also referred to as texture coordinates.

See also:
Texture Coordinates

UVA Format

This is a RenderWare Graphics file format for exporting UV animations.
