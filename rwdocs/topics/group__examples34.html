Examples
[3.4]

New examples for RenderWare Graphics 3.4 are listed below.

Animation Toolkit Example

We have produced an example of keyframe animation that interpolates the radii and color of light sources, produced by the toolkit.

Decal Example

We have produced a decal example based around our dungeon level, showing an efficient decal drawing example that uses the PTank functionality.

Maestro1 Example

Maestro1 demonstrates how to create and link up a 2d user interface. Specifically featured are methods of piping controller button pushes into the Maestro animation player. Also shown is how to make the animation trigger external events via the "GetURL" mechanism.

PrtStd Example

The particle standard example demonstrates the use of the PrtStd plugin by creating a default particle system with the standard properties for box emitter; color animation; and size animation.
