Detailed Description

Crowd, team and toon.

FXPack Overview

The FXPack, a chargeable optional extra, contains:

  • RpCrowd Plugin Overview - efficient rendering of animated billboard crowds
  • RpPrtAdv Plugin Overview - advanced particles system
  • RpTeam Plugin Overview - develop teams of players similar in construction
  • RpToon Plugin Overview - achieve cartoon-like 3D graphics

  • RtToon Toolkit Overview - Provides functionality for creation and editing of toon data
