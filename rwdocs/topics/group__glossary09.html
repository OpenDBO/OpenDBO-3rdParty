2d Converter Tool

2dconvrt is primarily an importer of Flash .swf files into the RenderWare Graphics .anm format. These files may then be played back with the 2dviewer viewer, which uses the Rt2dAnim library.

See also:
Maestro , ANM Format , SWF Format , 2d Viewer , Tools

2d Viewer

A command line tool which allows various 2d files to be loaded and displayed back. Supported formats are 2D .anm (Maestro and simple animations) and .dff (animatable 2d objects, e.g. shapes, text strings, scenes) files.

See also:
Maestro , ANM Format , DFF Format , Viewers

32 bit Color

32 bit color is a format for encoding color that uses one byte each for red, green and blue, with one byte for an alpha value.

See also:
Alpha Channel

3ds max

3ds max is a modeling package used to create worlds, objects and characters. It can be used with a RenderWare Graphics exporter to create files that a RenderWare Graphics application can read and visualize.

See also:
Maya , Exporter
