RenderWare Graphics API Reference

3.7

This document provides an API Reference for release 3.7 of the RenderWare Graphics SDK.

RenderWare Graphics is a 2D and 3D graphics API used by game developers to create real-time 3D graphics applications, such as computer games and simulations. It contains a comprehensive set of tools, plugins and libraries which enable game developers to create games on the leading platforms - PC, GameCube, PlayStation 2, and Xbox.
