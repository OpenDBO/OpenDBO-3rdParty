Fundamental Types

Fundamental Types Overview

Fundamental Types contains:

  • Misc Data Types - fundamental data types
  • Integer Types - integer types
  • Real Types - real types
  • Geometrical Types - geometrical types which includes bounding boxes, lines, rectangles and spheres
    • RwBBox Overview - bounding box
  • Vector Types - includes 2D, 3D and 4D vector types
    • RwV2d Overview - 2D vectors
    • RwV3d Overview - 3D vectors
    • RwV4d - 4D vector data structure
  • Matrix Types
    • RwMatrix Overview - includes rotation, multiplication, scaling and translation of matrices
  • RwRGBA Overview - color and alpha using RGBA
