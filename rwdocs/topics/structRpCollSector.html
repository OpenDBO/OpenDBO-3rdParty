RpCollSector Struct Reference
[RpCollision]

Detailed Description

This opaque type represents a node of an RpCollTree, and corresponds to a region of space within an axis aligned bounding box. A branch sector references a pair of overlapping sub-sectors, and a leaf sector references any entries that are contained within the region.
