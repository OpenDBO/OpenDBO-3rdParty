Scene Management

Scene Management Overview

Scene Management contains:

  • RpClump Overview - containers for RpAtomic's
  • RpWorld Overview - 'master' object for RenderWare Graphics' Retained Mode API
  • RpWorldSector Overview - static geometry
  • RwCamera Overview - extends RwCamera API
  • PVS
    • RpPVS Plugin Overview - potentially visible sets
    • RtSplinePVS - generate PVS data using a spline for a world.
  • RpLODAtomic Plugin Overview - high-level support for LOD management
  • RpUserData Plugin Overview - store user defined data with geometry
