RwTexture* RwD3D9DDSTextureRead (  const RwChar *    name,
const RwChar *    maskname
) 
 

RwD3D9DDSTextureRead creates an RwTexture from a DDS file. This function currently supports all different flavors of DDS files, including DXT compressed textures, cube textures and mipmaps. The function will append a .dds extension to the filename. For example, the following line of code will search for test.dds.dds: 

RwD3D9DDSTextureRead( "test.dds", NULL );

If you try to load a texture with a format not supported by the video card drivers, RWD3D9 will automatically convert the texture to the most suitable texture format.

For more information on DDS files, DXT compressed textures and cube textures, see the D3D9 SDK documentation.

Parameters:
name  Name of the DDS file to be opened. Can be an absolute path or just a file name. In this case, the function will search for the file in the search path.
maskname  Currently unused
Returns:
The RwTexture on success or a NULL pointer on error.
