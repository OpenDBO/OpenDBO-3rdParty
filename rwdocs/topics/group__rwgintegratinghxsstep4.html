Step 4 - Registering Part 1
[Integrating HXS with MSDN Collection]

This step details registering the namespace and the help file using Microsoft Help File Registration Tool (hxreg.exe).

  1. Register the namespace. In the output directory, c:\rwoutput at the command prompt: 

       hxreg -n RWG.D3D8 -c d3d8.hxc -d "RenderWare Graphics API Reference - D3D8"

    • hxreg - Microsoft Help File Registration Tool
    • -n RWG.D3D8 - namespace (this is the same as the namespace specified in Step 2)
    • -c d3d8.hxc - collection name
    • -d "RenderWare Graphics API Reference - D3D8" - namespace description
  2. Register the help file. In the output directory, c:\rwoutput at the commmand prompt: 

       hxreg -n RWG.D3D8 -i RWG.D3D8.ID -x d3d8.hxi -s d3d8.hxs
    • hxreg - Microsoft Help File Registration Tool
    • -n RWG.D3D8 - namespace (this is the same as the namespace specified in Step 2)
    • -i RWG.D3D8.ID - title ID (this is the same as the title ID specified in Step 2)
    • -x d3d8.hxi - index file
    • -s d3d8.hxs - help file
This .hxs file has been registered as a stand alone help file. This .hxs file can be viewed as a stand alone help file or integrated with the MSDN Collection.

To view the stand alone .hxs file refer to the Step 6.

Note:
If .hxs files are moved, the new path needs to be registered.
