Cube Textures
[D3D9]

RenderWare Graphics supports cube textures via the RwD3D9DDSTextureRead function. This function will load .dds files that contain cube and non-cube textures with compressed and uncompressed formats.

A cube texture has to be square.

The RpMatFX plugin detects if the texture used for Environment mapping is a cube texture, and set automatically the appropriate texture stage states.
