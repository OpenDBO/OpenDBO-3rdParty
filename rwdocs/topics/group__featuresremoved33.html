Features Removed
[3.3]

  • RpAnim and RpPrtSys plugins have been removed from the SDK.
  • RtHAnimCnv toolkit has been removed.
  • Support for Direct3D 7 has been removed

Structural Changes to RenderWare Graphics in Version 3.3

With a constantly changing and improving product like RenderWare Graphics, it is sometimes necessary to make some changes to how it works or is used. In RenderWare Graphics 3.3 the only change that we have made is the removal of source for the Exporters.

With the introduction of the user data feature, rather than changing the RenderWare Graphics exporter source, you can now attach arbitrary user data to any exported object to achieve your custom results.
