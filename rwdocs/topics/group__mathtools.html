Detailed Description

Includes barycentric, quaternion, slerp, spline and bézier mathematical tools

Math Tools Overview

Math Tools contains:

  • RpRandom Plugin Overview - 31-bit pseudo-random number generator
  • RpSpline Plugin Overview - use and manipulation of interpolating cubic uniform B-Spline curves.
  • RtBezPat Toolkit Overview - supports Bézier patches and RpPatch
  • RtBary Toolkit Overview - map points between the barycentric space defined by a triangle and Cartesian space
  • RtIntersection Toolkit Overview - test geometry primitives intersects
  • RtQuat Toolkit Overview - quaternion arithmetic and conversion to other formats
  • RtRay Toolkit Overview - operations on lines
  • RtSlerp Toolkit Overview - interpolating rotations between two matrices
