Detailed Description

This parameter block may be passed to the functions RpCollisionWorldSectorBuildData, RpCollisionWorldBuildData and RpCollisionGeometryBuildData to control the generation of collision data (otherwise a NULL argument indicates that default settings should be used). The function RpCollisionBuildParamInitDefaults can be used to initialize the parameters to their default settings.
