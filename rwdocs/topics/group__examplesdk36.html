Examples - SDK
[3.6]

BurningM

This example demonstrates a burning man effect. A simple particle system, using a PTank for the rendering, is animated using a skinned character as an emitter.

ImShadow

This example has a new menu option that allows you to switch between generic and platform-specific pipelines to render the shadows.

MemHints

This example shows you how to sensibly manage your runtime memory allocations by exploiting a new RenderWare parameter.

NormMap

This example shows you how to use the normal map plugin for rendering any geometry using a normal map in texture space, and is now shipped for D3D9 too.

PBlaster

This example demonstrates blaster gun effects, using both 3D matrix-based particles to generate the laser beams, and screen aligned particles for the charging effect. It shows you how to use PTank atomic objects to create some custom particles.

PickUp

This example demonstrates health-pack pickup effects, using one PTank atomic per pickup.

Toon

This example has a new menu layout that allows you to switch between generic and platform-specific render callbacks.

UVAnim

This example demonstrates the use of the uvanim plugin. Playback of animations that were applied to materials within the exporters is demonstrated. Examples of how to create and apply animations are provided. Use of the RtDict toolkit is also demonstrated.
