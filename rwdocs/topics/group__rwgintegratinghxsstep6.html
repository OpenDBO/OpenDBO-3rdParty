Step 6 - Viewing
[Integrating HXS with MSDN Collection]

  1. View your completed project using Microsoft Document Explorer (DExplore) viewer. 

       "C:\Program Files\Common Files\Microsoft Shared\Help\DExplore.exe" /helpcol ms-help://RWG.D3D8

    The full path to a file in a collection is: 

       ms-help://namespace/titleId/path/file.htm

    To view the RenderWare Graphics D3D8 API Reference 

       ms-help://RWG.D3D8/RWG.D3D8.ID/main.html

    To view the Visual Studio help file 

       ms-help://MS.VSCC/vsccCommon/html/vsccCommon_Start_Page.htm

    • ms-help - MS Help 2
    • MS.VSCC - namespace representing the Visual Studio .NET collection.
    • vsccCommon - .hxs title registered under the MS.VSCC namespace.
    • html/vsccCommon_Start_Page.htm - is the path to a topic within the vscccommon.hxs help title containing vsccCommon_Start_Page.htm.
Note:
Alternatively the MS Help 2.0 Custom Viewer can be used for viewing .hxs files and displaying a list of all the registered namespaces. This viewer is available from:
  • http://www.mvps.org/htmlhelpcenter/mshelp2/h2view.html
