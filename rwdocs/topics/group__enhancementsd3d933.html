Enhancements - D3D8
[3.3]

In RenderWare Graphics 3.3 we have enhanced the PC platform specific implementation to provide improved performance, with optimized performance for the new Lightmaps and Particle Systems plugins.

SSE Assembler Skinning

This new skinning implementation, where supported on the PC hardware typically provides a 10% to 20% skinning performance improvement. The SSE Assembler Skinning includes support for skinned-patched models, and is available for D3D8, OpenGL and for the RenderWare Graphics Software Rasterizer plugin.

We have also added support for DirectX8.1 for the D3D8 implementation of RenderWare Graphics.
