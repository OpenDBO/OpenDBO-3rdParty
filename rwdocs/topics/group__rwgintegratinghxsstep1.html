Step 1 - Converting
[Integrating HXS with MSDN Collection]

This step details converting the .chm to \.hx* files using the Microsoft Help 2.0 Converter (hxconv.exe).

  1. Create an output directory for the output files, for example. c:\rwoutput

  2. In the RenderWare Graphics API Reference directory C:\RW\Graphics\docs\apireference at the command prompt: 

       hxconv -o c:\rwoutput d3d8.chm

    • hxconv - Microsoft Help 2.0 Converter
    • -o c:\rwoutput - output directory
    • d3d8.chm - RenderWare Graphics API Reference
  3. In the c:\rwoutput directory, hxconv has converted the .chm to the following file formats:
    • html - copy of .html topic files used to build API Reference
    • png - copy of .png files used to build API Reference
    • hxc - Microsoft Help Collection Definition file, for example, d3d8.hxc. The .hxc is equivalent to .col (the collection file) and .hhp (the project file). The project files are listed in the .hxf file.
    • hxf - Microsoft Help Include file, for example, d3d8.hxf. The .hxf file contains a list of all the files to be included in the compiled .hxs help file.
    • hxk - Microsoft Help Index file, for example, index.hxk and NamedURLIndex.HxK. The index.hxk file is equivalent to .hhk. The NamedURLIndex.HxK file contains valid DefaultPage and HomePage entries.
    • hxt - Microsoft Help Table of Contents file, for example, index.hxt. The .hxt is equivalent to .hhc.
