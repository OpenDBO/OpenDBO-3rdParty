Software Required
[Integrating HXS with MSDN Collection]

The following software needs to be installed for these steps to be completed successfully.

  • MSDN Help 2, for example, January 2003
  • Visual Studio Help Integration Kit
  • Visual Studio .NET (this is not essential for building .hxs files)
Download and installation details are detailed below.

Visual Studio Help Integration Kit (VSHIK)

  1. Download the VSHIK installer. A link can be found: http://helpware.net/mshelp2/h2faq.htm#novsnet
  2. Install VSHIK to a local temporary folder, for example, C:\VSHIKTemp
  3. Download patch_vshik_setup.msi.zip and unzip to a local temporary folder, for example, C:\VSHIKTemp
  4. Run patch_vshik_setup.msi.vbs
  5. Run <codesetup.exe to install VSHIK to C:\Program Files\VSHIK
  6. Create a shortcut on your desktop to the VSHIK help setting the target field to: 
     "C:\Program Files\Common Files\Microsoft Shared\Help\dexplore.exe" /helpcol ms-help://ms.vscc

Conversion Programs

There are 3 conversion programs which are installed when VSHIK (or Visual Studio .NET) is installed:
  1. hxconv.exe
  2. hxcomp.exe
  3. hxreg.exe
These are used in steps 1 - 3 and can be found in one of the following directories:
  • C:\Program Files\Microsoft Visual Studio .NET\Common7\IDE
  • C:\Program Files\Microsoft Help 2.0 SDK
Note:
To shorten the length of the examples, the path containing hxconv.exe, etc has been added to the path environment variable.
