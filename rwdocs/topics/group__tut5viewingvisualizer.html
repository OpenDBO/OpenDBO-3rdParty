Viewing in Visualizer
[Tutorial 5 - Creating a World]

We can view the world using RenderWare Visualizer.

When RenderWare Graphics is initially installed there is an option to install the exporters. The RenderWare Graphics exporters are installed if there is a RenderWare menu in 3ds max.

The exporters use XML templates to store export settings. These settings are explained fully in the exporter documentation.

  • RenderWare->View... displays the Export Wizard.
  • Set the target directory to: C:\RW\Graphics\Examples\Tutorials\Tutorial5\Models. Click Next.

  • Set the project template file to Generic.rwt. Click Next.
  • In the final screen, select Use as Default. This option saves the project template used and directory settings.

    Click Finish. The default view settings create a temporary .rws file which is now displayed in Visualizer.

    Navigation in RenderWare Visualizer

    The navigation controls are intuitive. The keyboard and mouse shortcuts to move around the viewer are:

    Control Description
    Left click & drag Mouse Look. Position static, but changing view position
    Right click Activates and deactivates orbit mode. To activate orbit mode, depress the right mouse button and keep it depressed. Move the mouse or use the keyboard for navigation. Release the right mouse button to deactivate orbit mode.
    Left cursor key or D Strafe left
    Right cursor key or A Strafe right
    Up cursor key or W Forward
    Down cursor key or S Backward
    Esc Exit application if in the Viewer window

  • Close RenderWare Visualizer by clicking on the close button of the Control Panel.
