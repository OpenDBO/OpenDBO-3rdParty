Introduction
[Integrating CHI with MSDN Collection]

The RenderWare Graphics API Reference is in .chm (compiled HTML) format. A .chi (compiled HTML index) is also included in the SDK. The .chi can be used to integrate the RenderWare Graphics API Reference with the MSDN Collection. Integrating the RenderWare Graphics .chi with MSDN Collection enables the developer to obtain help on a selected RenderWare Graphics identifier by hitting <F1>, which immediately jumps to the relevant page.

The MSDN collection is stored in XML format.

There are two files that need to be edited to integrate a .chi with the MSDN Collection.

  • msdnxxx.col - the collection
  • hhcolreg.dat - the collection's registry
Note:
The name of the .col file starts with msdn. For example the April 2000 file is called msdn010.col.
