Detailed Description

The User Guide is organized into three volumes of general, platform independent material offering a structured guide to each module.

  • User Guide Volume I - core and world libraries including basic immediate mode and retained mode functionality.
  • User Guide Volume II - animation systems, special effects and world management functionality
  • User Guide Volume III - utility libraries (including Maestro), PowerPipe and Recommended Reading
For GameCube, PlayStation 2 and Xbox a separate user guide contains platform specific material.
