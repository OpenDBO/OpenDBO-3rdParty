[Glossary]

Glossary entries beginning with M.

Maestro

Maestro is a collection of RenderWare Graphics components that can be used for the design and playback of 2D user interfaces in games. The user interface is typically designed using Macromedia Flash.

See also:
Rt2dMaestro Overview , FLA Format , RWS Format , 2d Converter Tool , 2d Viewer

MakeFont Tool

This Microsoft Windows console program can be used to create METRIC1 BMP fonts from True Type fonts, for use with the Rt2d toolkit. The program creates the .bmp file and the .met file for the font.

See also:
Rt2d Toolkit Overview , BMP Format , MET Format , Tools

Maya

Maya is a graphics package used to create worlds, objects and creatures. It can be used with a RenderWare Graphics exporter to create files that a RenderWare Graphics application can read and visualize.

See also:
3ds max , Exporter

Mel Script

Mel is a scripting language for Maya. MEL Script files are files containing MEL commands.

See also:
Maya

MET Format

This RenderWare Graphics text file format is used to describe a font's metric. It is used by the Rt2d toolkit.

See also:
MakeFont Tool , Rt2d Toolkit Overview , Rt2d Font Format

Metrics

Data collected from a metrics build of an application that helps in performance tuning.

Metrics Build

A version of the RenderWare Graphics libraries that is instrumented and collects rendering information such as the number of vertices transformed per frame.

Middleware

Software that makes it easier to develop games by providing a core of working, tested functionality common to many game types.

Mipmap

In 3D computer graphics it is common to map a bitmap to a surface to give texture or detail. As the surface gets further away the quality of the reduced image deteriorates and the time it takes to process it is not reduced in proportion to its size. It helps to provide alternative versions of such bitmaps to different scales for different distances: not bitmaps but one mipmap. Mipmaps are supported in the RpMipmapKL plugin and the RtMipmapK toolkit.

See also:
RpMipmapKL Plugin Overview , RtMipK Toolkit Overview

Modeling Package

A modeling package is an application, like 3ds max or Maya, that is used to draw the textures, worlds, characters and other assets that make up a game's world.

See also:
3ds max , Maya , Assets , Exporter

Morph Target Animation

3D computer models are made of many points in space, covering the surface of an object. A morph target is a set of these points that define the start or end state of an animated object. Morph targets define states of the same object, using points that correspond in both targets. The morph targets might be a drinks can and the same can crushed, or a human face, and the same face smiling. Thus morphing is the process of transforming smoothly between the two morph targets. Delta morphing transforms between more than two morph targets. Morphing is supported in the RpMorph plugin.

See also:
Delta Morph , RpMorph Plugin Overview

MTD Format

RenderWare Graphics file format containing material effect dictionary data.

MTE Format

RenderWare Graphics file format containing multi-texture effect data. The data contained within the effects will be specific to a particular platform.
