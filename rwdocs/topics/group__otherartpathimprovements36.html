Other Art Path Improvements
[3.6]

UV Animation

As promised, we are delivering the second part of our UV animation solution in RenderWare Graphics 3.6, connecting the art-path from 3ds max/Maya into RenderWare Graphics. Keyframe animation of UV transforms is now supported in the art tools, plus you can preview the results thanks to full Visualizer support.

The new UV animation plugin, RpUVAnim provides a way of applying animations to the UV transform of a material.

The associated documentation has been updated to help you get the most out of the complete feature.

Visualizer

The Visualizer now supports the TIFF file format.

Art Tools Improvements

Maya 5

We now support Maya 5.

Texel-based UV Limits

The limiting of UV's coordinates now defaults to a Texel-based format. This allows you to set a limit in texels so that the final UV limit applied will adapt, based on texture size. The standard UV based mechanism is still available.

Preserving Bone Order

We have developed a number of new options to help preserving bone ordering on export. For example, the order of traversal can now be done on boneID, bone name, etc.

Greater Control of the Export Target

The Export path and filenames can now be set on a per-asset basis. In addition to this, target asset filenames can now be previewed & managed in the 'advanced settings' window.

Template Update Tool

This new tool updates your template files to 3.6 by adding some new options and renaming options that have changed. It is available from the Tools menu within 3ds max and Maya and may be used on a single template file or a whole directory of files.

Better Bounding Spheres

Bounding spheres on skinned geometries are now more accurate.

Open Export Improvements

Chaining Export Objects

We've developed a new plugin mechanism allowing export objects to be chained rather than simply extended. This allows the use of multiple plugins affecting the same export object.

More OpenExport examples

More OpenExport examples included in RenderWare Graphics 3.6 are:
  • Custom 3ds max and Maya shaders with OpenExport and RF3 integration
  • Customisation of the RenderWare particle system
  • Generation of export log files
