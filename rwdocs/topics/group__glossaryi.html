Glossary entries beginning with I.

IDE

Integrated Development Environment. A software package that is used to develop computer software, like a word processor for programs. Examples are Microsoft Visual Studio, and Metrowerks CodeWarrior.

INK Format

This is a RenderWare Graphics file format for storing Toon Ink dictionaries.

Note:
This file format is now considered legacy. The binary format of this file will continue to be supported, and this release of RenderWare Graphics continues to read them. There is no need to re-export existing artwork to .rws file format. However, it is recommended that you export to .rws files as this file format may be removed in future releases.
See also:
RWS Format

Instance Tool

The instance tool can be used to optimize RenderWare Graphics files for target platforms.

See also:
Instancing , Tools

Instancing

The process of generating a platform specific representation of a renderable object from the platform independent representation.
