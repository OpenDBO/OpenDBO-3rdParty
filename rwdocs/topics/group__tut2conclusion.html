Conclusion
[Tutorial 2 - User Interaction]

In this exercise we have further developed an application to support user interaction. Because we have been using the PC as a development environment, we have used the mouse as an input device. If this code was to run on other platforms, then the input might need to be re-thought. Most consoles do not support a mouse, and so selecting a cube by moving a cursor will not work. An alternative solution might be to use a button on the pad to select between the different atomics in the application.
