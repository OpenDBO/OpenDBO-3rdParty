Documentation Available
[Documentation]

The documentation covers all parts of the SDK.

RenderWare Graphics is supplied with:

  • Top-level
readme_Win.pdf, containing configuration information.

  • This API Reference
  • User Guide - offers a structured guide to each module. The User Guide is divided into 3 volumes and includes Maestro documentation and Recommended Reading.
  • Exporter Documentation (if installed) - RenderWare Graphics exporters for 3ds max and Maya including tutorials.
  • Examples Documentation - RenderWare Graphics examples displaying different functionality available.
  • Tools Documentation - RenderWare Graphics tools including rf3cc and instance.
  • Viewer Documentation - RenderWare Graphics viewers can be used to view all RenderWare Graphics export file formats.
  • White Papers - generic and platform specific white papers.
  • Glossary - RenderWare Graphics terminology including a list of all RenderWare Graphics file extensions.
  • SearchPDFs.pdf describes how to search all PDFs using index.pdx. (See also PDX Format)
  • readme.txt files for each of the supplied Examples.
  • D3D9 Platform Specific Overview - Links to all documentation and functions for the current platform.
  • Tutorials - tutorials for the PC
  • AppWizard.pdf - RenderWare AppWizard is a Visual Studio 6 AppWizard that builds an MFC framework for a RenderWare Graphics application capable of rendering animated and skinned objects in a window.
