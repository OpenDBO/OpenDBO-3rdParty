Floating-point Precision Mode
[D3D9 General Information]

Note:
This section only applies if the RenderWare SDK has been built with available assembler code. This is the default case.
Upon calling RwEngineStart and RwCameraBeginUpdate (i.e. every frame), D3D9 RenderWare Graphics forces the FPU into single precision mode. This increases the performance of x96 assembler mathematcial functions that are used in RenderWare Graphics.
