[Integrating CHI with MSDN Collection]

MSDN Integration Utility

More information about intergrating CHIs in MSDN can be found: www.codeproject.com/winhelp/msdnintegrator.asp

HTML Help Workshop

Microsoft HTML Help Workshop was used to generate the .chm and .chi. It can be downloaded free of charge from: www.microsoft.com

To ensure that the .chi is generated correctly the following options need to be set in the .hhp (HTML Help Project):

  • Binary TOC=YES
  • Create CHI file=YES

Doxygen

This RenderWare Graphics API Reference has been built using Doxygen. To create .chi file for integration in the MSDN Collection the Doxygen options BINARY_TOC and GENERATE_CHI must be set to YES.

For further information: www.doxygen.org
