Introduction
[Tutorial 5 - Creating a World]

In this tutorial we will modify our application to use a simple world, exported from 3ds max. The world will be prelit so that RenderWare Graphics does not have to illuminate it. This tutorial assumes that you have a basic grasp of modeling with 3ds max. To view the world we also extend the viewing model so that the camera can be rotated. The source code used as the starting point for this tutorial can be found in the Examples/Tutorials/Tutorial5 folder. It is a copy of the final code written in Tutorial 4.
