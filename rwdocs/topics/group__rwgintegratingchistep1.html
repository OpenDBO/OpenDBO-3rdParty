Step 1 - Locate msdnxxx.col
[Integrating CHI with MSDN Collection]

The location of the .col file can be found in the system registry, using regedit: 
   HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\HTML Help Collections\Developer Collections

The registry also states the language used, for English the setting is 0x409.

Note:
For the April 2000 MSDN release, the file can be typically found: 
   C:\Program Files\Microsoft Visual Studio\MSDN\2000APR\1033\MSDN010.COL
