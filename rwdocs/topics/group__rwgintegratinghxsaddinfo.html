Microsoft Unsupported Tools

If you have Microsoft Help 2.0 SDK installed (default location C:\Program Files\Microsoft Help 2.0 SDK), in the Unsupported Tools directory there is a Namespace.exe file. This file initializes the HTML Help - Collection Manager which lists all the registered namespaces and the locations of the .hxs and .hxi files.
