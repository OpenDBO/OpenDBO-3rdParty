Introduction
[Tutorial 1 - Loading a Simple Model]

The best way to start learning how to use RenderWare Graphics is to start using RenderWare Graphics! This document will guide you through the process of writing your first RenderWare Graphics application. To make things really easy we will use much of the functionality used in the examples, which are based on a skeleton RenderWare Graphics project called template. This first RenderWare Graphics project will simply start up RenderWare Graphics, allow you to load a cube model, and shut RenderWare Graphics down.
