RenderWare Graphics Plugins and Toolkits

Plugins & Toolkits List Overview

Below is an alphabetical list of plugins and toolkits that are included in all versions of RenderWare Graphics.

Plugins

Plugin Description

RpAnisot Plugin Overview Anisotropy extension for extending textures

RpHAnim Plugin Overview Hierarchical animation plugin
RpLODAtomic Plugin Overview Level Of Detail extensions for RpWorld's "RpAtomic" object
RpLtMap Plugin Overview Render geometry using detailed static lighting information from lightmap textures

RpMipmapKL Plugin Overview Texture mipmap "K" and "L" value extensions
RpMorph Plugin Overview Morph-target animation extensions
RpPatch Plugin Overview Bézier patch rendering engine
RpPrtAdv Plugin Overview Advanced particles system
RpPrtStd Plugin Overview Particle animation plugin
RpPTank Plugin Overview Creation, management and rendering of user customizable particles
RpPVS Plugin Overview Fast visibility culling extension for RpWorld, using Potentially Visible Sets
RpRandom Plugin Overview Platform-neutral random number generator
RpSkin Plugin Overview Skinned model rendering extensions with multiple bone weights per vertex
RpSpline Plugin Overview Spline manipulation extensions
RpTeam Plugin Overview Develop teams of players similar in construction
RpToon Plugin Overview Provides functionality for cartoon-like 3D graphics
RpUserData Plugin Overview Provides functionality for storing user defined data with geometry
RpUVAnim Plugin Overview Attaches UV animations to materials
