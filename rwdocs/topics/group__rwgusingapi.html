Using the API Reference
[Structure]

RenderWare Graphics API Reference gives you information about functionality in all plugins and toolkits.

Each plugin and toolkit contains an overview page discussing the use of the the plugin or toolkit. This section includes a requirements section listing header and libraries required and the functions required to attach these plugins and toolkits.

In the API Reference, all API functionality displays the full syntax, including links to associated documentation.

Documented API:

  • Data Structures
  • Defines
  • Enumerations
  • Functions
  • Typedefs
  • Variables
RenderWare Graphics API may contain the following sections:
  • Description - a description about the functionality and how it can be used
  • Example - example code
  • Parameters - a list of the parameters
  • Return values - return values
  • See also references - useful references
Note:
A list of new and removed API for the current release can be found in the Release Notes section.
