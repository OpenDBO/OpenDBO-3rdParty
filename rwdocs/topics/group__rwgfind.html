Index

Search Tab

To search for a specific terminology enter the word and press enter or use wildcards.

Searches are not case sensitive and punctuation marks are ignored.

Wildcards

  • * any number of missing characters, for example "l*t" finds light and lit
  • ? one missing character, for example "l?t" finds lit.
  • AND topics containing both words, for example, "clump AND atomic"
  • OR topics containing either word, for example, "bezier OR patch"
  • NOT topics containing the first word, but not the second word, for example,"raster NOT vector"
  • NEAR topics containing the first word within eight words of the second word, for example, "frame NEAR atomic"
