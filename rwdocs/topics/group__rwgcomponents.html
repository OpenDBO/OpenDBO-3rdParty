RenderWare Graphics Components
[Getting Started]

RenderWare Graphics is supplied as a number of libraries on the Software Development Kit (SDK). Applications will need to link against these libraries and include the associated header files. The requirements are listed at the top of each overview page for plugins and toolkits.

The RenderWare Graphics components can be broken down:

  1. Core Library - The Core Library must always be linked to your application as it provides basic rendering functionality.
  2. Plugins - Plugins can extend existing objects in both the Core Library and other Plugins. Includes the World Library (RpWorld) which provides RenderWare Graphics' Retained Mode API.
  3. Toolkits - Toolkits are normally ordinary libraries that make use of RenderWare Graphics features.
