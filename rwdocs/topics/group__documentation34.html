Documentation
[3.4]

New and extensively updated documentation for RenderWare Graphics 3.4 is listed below.

User Guide - New Chapters

The User Guide has new chapters on:
  • Lightmaps
  • Standard Particles
  • RtAnimation

User Guide - Updated Chapters

The User Guide has updated chapters on:
  • Hierarchical Animation
  • Rt2d
  • Pipeline Nodes
  • PowerPipe Overview

Exporter Guides

The Exporter Guides are divided between artist and programmer documentation.
  • The Artist Guides for 3ds max and Maya have been updated to include all new functionality. The Artist Guides consist of a reference guide and a tutorial document for each modeling package and a glossary.
  • An exporter SDK document aimed at the powerful Exporter Framework, new for RenderWare Graphics 3.4.

Viewer and Tool Guides

Viewer and tool guides have been produced/updated to accompany the following tools:
  • Visualizer viewer
  • Pre-instancer tool
  • RenderWare Build Tool (source distributions only)

API Reference

The API Reference guide is now organized by subject group, for example all lighting components are now kept together.

There is also an API user/help guide, explaining useful features such as wildcard searches.

New and significant updates to the API reference guide include:

  • RtAnim
  • PowerPipe (restructured)
  • RtSkinSplit

Tutorials (PC only)

Are now presented in .chm format (compressed HTML).

White Papers

The white papers have been updated for RenderWare Graphics 3.4.
