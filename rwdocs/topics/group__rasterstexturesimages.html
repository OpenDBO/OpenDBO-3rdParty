Rasters, Textures & Images

Rasters, Textures & Images Overview

Rasters, Textures & Images contains:

  • RwImage Overview - loading, saving and processing bitmaps
  • RwRaster Overview - platform-dependent representation of bitmaps
  • RwTexture Overview - RenderWare Graphics textures
  • Mipmapping - varying texture resolution for varying surface size
    • RpAnisot Plugin Overview - extends an RwTexture with a maximum anisotropy value
    • RpMipmapKL Plugin Overview - extends an RwTexture to contain "K" and "L" values.
    • RtMipK Toolkit Overview - calculates realistic "K" values for textures in RpClump and RpWorld
  • Texture Dictionaries
    • RwTexDictionary Overview - texture dictionary
    • RtPITexD Toolkit Overview - platform independent texture dictionary
  • Image Conversion Tools - image conversion tools
    • RtBMP Toolkit Overview - read and write BMPs
    • RtPNG Toolkit Overview - read and write PNGs
    • RtRAS Toolkit Overview - read and write RASs
    • RtTIFF Toolkit Overview - read and write TIFFs
