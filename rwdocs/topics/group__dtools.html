Detailed Description

2d, 2d Animation and Character Sets

2d Tools Overview

2d Tools contains:

  • RpLogo Overview - renders the RenderWare Graphics logo on screen
  • Rt2d Toolkit Overview - includes font handling; textured and colored brushes; fills; full support for outline and filled path
  • Rt2dAnim Toolkit Overview - 2d animation library supporting several different levels of animation on 2d objects.
  • RtCharset Toolkit Overview - simple, low-overhead text display
