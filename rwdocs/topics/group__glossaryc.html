[Glossary]

Glossary entries beginning with C.

Cel

Cel, short for "celluloid", refers to early cartoon film techniques like "cel shading", which is simulated by the RpToon plugin.

See also:
Toon

CHI Format

Compiled HTML Index. To use the RenderWare Graphics API Reference both the .chi and the .chm files are required. The .chi file stores all the indexing information. Both files should be stored in the same directory. The .chi can also be used to integrate RenderWare Graphics API Reference with MSDN.

See also:
CHM Format , Integrating with MSDN Collection

CHM Format

Compiled HTML. RenderWare Graphics API Reference is in .chm format to enable easier searching. It also decreases the number and size of files required to be shipped.

To view RenderWare Graphics .chm's you need Internet Explorer 4 and above.

See also:
CHI Format , Structure

CJK

Chinese, Japanese and Korean.

RenderWare Graphics supports these fonts using Unicode in UTF-8 format.

See also:
UTF , Unicode , MET Format , Rt2d Font Format , MakeFont Tool

Clump

A container for atomics, lights and cameras. A clump is not visible, and provides a root for a frame hierarchy.

See also:
RpClump

Clump Viewer

Used to load and explore clumps in .dff file format. See the Clump View and World View Viewer document for more information. Note that only .dff files containing 3d assets may be viewed with Clump viewer.

See also:
DFF Format , Viewers
