[Glossary]

Glossary entries beginning with V.

VCL

Vector Command Line. This tool generates optimized PlayStation 2 Vector Unit code from a single VU instruction stream.

Vector

A mathematical representation usually consisting of three values that describe distances in each of the three dimensions of Cartesian coordinate space. A vector may represent a point in space from 0,0,0; it may represent a direction; but it is versatile enough to be processed and interpreted in many ways useful in computer graphics. Various vector formats are supported as basic types in RenderWare Graphics.

View Frustum

The volume that defines a camera's field of view is, in principle, a pyramid not a frustum. The tip of the pyramid is inside the camera. In practice, the objects nearest to the camera and objects over a certain distance away from it are not rendered. This means that the volume viewed by a camera is a frustum.

Viewers

RenderWare Graphics has viewers for viewing models, streams and maestro.

  • Clump Viewer for viewing .dff files
  • Visualizer for viewing many types of RenderWare Graphics files
  • World Viewer for viewing .bsp files
  • Stream Viewer for viewing the contents of a binary stream files
  • 2d Viewer - a command line tool for use with Maestro.

Visualizer

RenderWare Visualizer can view .anm, .bsp, .dff, .rf3 and .rws file formats. The .rws file format saves all export formats in one file, to display the whole of a scene at once. RenderWare Visualizer is documented in RenderWareVisualizer.pdf.

Voxel

Voxels are small volume elements. Pixels are the small elements that make up a picture, so, by analogy, voxels are small bits of a volume.

VU Code

Special software that is written to run on one of the processors in the PlayStation 2. Writing good VU code is legendarily hard.
